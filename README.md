# TechRent

Proyecto para gestionar el alquiler de equipos electrónicos.

**Estado del repositorio: inicial.** La rama principal contiene un [`.gitignore`](.gitignore) basado en una plantilla de AL para Dynamics 365 Business Central. Con los archivos actuales todavía no hay una aplicación que se pueda instalar o ejecutar. La plataforma definitiva queda por confirmar.

## Alcance por definir

- Qué datos identifican cada equipo y cómo se consulta su disponibilidad.
- Cómo se registran la entrega y la devolución de un equipo.
- Qué debe demostrar la primera versión y quién va a usarla.

Cuando exista el primer módulo, agrega aquí cómo iniciarlo, sus dependencias y los pasos para comprobar un alquiler de principio a fin.
